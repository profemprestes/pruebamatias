# **App Name**: Kiddo Quizvite

## Core Features:

- Interactive Quiz: Presents up to 6 questions related to the birthday child. The user needs to answer at least 3 correctly to proceed to the invitation.
- Interactive Invitation: Displays an interactive invitation card with the child's name, photo placeholder, and a brief message. Clicking the card reveals party details.
- Contact Information: A modal or popup that shows the parents' names and a contact number.

## Style Guidelines:

- Primary colors: Bright and cheerful: Sunny yellow, sky blue, and bubblegum pink.
- Accent color: A vibrant teal (#008080) for interactive elements (buttons, links).
- Clean one-page design (for the invitation), with clear sections and smooth scrolling between them (once accessed). The home page will have its own structure for the questions.
- Simple and fun icons for date, time, and place.
- Subtle animations for the loading screen and transitions (both on the home page and in the invitation).
